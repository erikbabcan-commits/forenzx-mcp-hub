# Code of Conduct

## Our pledge
This project serves forensic analysts and investigators. Evidence integrity, honesty and respect are core values here — including in our community.

## Standards
- Be professional and respectful; no harassment, personal attacks or discriminatory conduct.
- Do not submit fabricated test results, fake PASS reports, or evidence-impacting changes disguised as tooling.
- Respect confidentiality: never commit real case data, evidence, or secrets.
- When something is not verified, say so.

## Enforcement
Reports go to the maintainers via a private GitHub message or security advisory. Maintainers may remove contributions or ban contributors for violations.
